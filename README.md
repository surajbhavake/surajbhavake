## ⟢ About

I build backend systems — APIs, data models, and the infrastructure that keeps them running under real traffic. My core stack is **Django** and **Django REST Framework**, backed by relational databases and containerized with **Docker**, with **React** on the frontend when the product needs one.

I care about code that reads clearly, scales without drama, and doesn't need a rewrite in six months. Currently deepening my understanding of **cloud infrastructure** and **distributed systems** — the layer above "does it work" that asks "does it survive production."
